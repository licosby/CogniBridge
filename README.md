CogniBridge Hub is an enterprise executive function assistant and cognitive workload decompiler designed around the **5 Pillars of Human-Centered AI (HCAI)**. Built specifically to mitigate digital burnout, context-collapse, and executive dysfunction for neurodivergent and overwhelmed knowledge workers, it transforms dense technical specifications and corporate memos into structured, actionable micro-steps—all running 100% locally in the browser with **zero server infrastructure costs**.

---

## 🌟 Key Features

### 1. Dynamic Cognitive Decompiler
* **Unbounded Micro-Milestone Generation:** Intelligently breaks down complex deliverables (e.g., distributed database migrations, meeting hosting, large event planning) into concrete, sequential action items without artificial step limits.
* **1-Click Container-Level Inline Editing (`✏️`):** Empowers users to edit task titles and customized step sequences on the fly, keeping the human operator in complete control.
* **Per-Task Accordions & Macro Collapsing:** Allows neurodivergent users to individually collapse non-active cards down to a clean single line to eliminate visual crowding.

### 2. The Reverse Accomplishment Calendar ("Done Log")
* **Accomplishment Tracking vs. Speculative Scheduling:** Instead of filling calendars with anxiety-inducing future to-do lists, the system records exactly what was completed and timestamps each accomplishment.
* **Direct Date-Button Triggers:** Clicking any date cell opens the full **Day Dossier**.
* **Date-Bound Memory Vault:** Drag-and-drop or upload scanned birthday cards, event badges, certificates, photos, or documents to archive them permanently with that specific calendar date.

### 3. Online Naive Bayes Machine Learning & Active Learning
* **Multinomial Naive Bayes Classifier:** Computes real token log-likelihoods with Laplace smoothing to probabilistically categorize tasks into **Work / Professional** vs. **Personal**.
* **Adaptive Human Co-Pilot:** Provides 1-click domain switching badges (`💼 WORK` / `🏠 PERSONAL`). Switching a domain triggers on-device active learning, continuously retraining model priors and vocabulary weights in local memory.
* **Domain Segregation Controls:** Dedicated view toggles for **"See All"**, **"Work Tasks Only"**, and **"Personal Tasks Only"**.

### 4. Passive Email De-Jargonizer & Filing Cabinet
* **Corporate Memo Parsing:** Automatically detects non-actionable, jargon-dense communications (e.g., restructuring updates, synergistic pivots) and avoids forcing irrelevant checkboxes.
* **Plain-English Deconstruction:** Synthesizes memos into high-level TL;DRs, actionable takeaways, and an interactive **Salience / De-Jargon Matrix**.
* **Dedicated Document Drawer:** Clean, searchable filing cabinet archive for historical memos without unsolicited email generation.

### 5. Web Audio Ambient Synthesizer
* **In-Browser Soundscape Generation:** Native Web Audio API pink noise and soft rain audio synthesis for continuous acoustic focus—with zero external audio assets or streaming bandwidth.
